# Changelog

All notable changes to PC Monitor.

## [1.0.0] - 2026-05-30

### Added
- Real-time process monitoring dashboard with 3-second auto-refresh
- System stats: CPU %, RAM usage, disk space, uptime, process count
- Smart process intelligence database recognizing 50+ common Windows processes (Chrome, VS Code, PostgreSQL, Redis, Defender, Node, Nginx, etc.)
- Three-tier safety rating system (Safe / Caution / Critical) with color-coded rows
- Kill Process button with confirmation dialog and system-critical process protection
- Category filter dropdown (Browser, IDE, DevTool, System, Terminal, etc.)
- Risk level filter (Safe, Caution, Critical)
- Search by process name or PID
- Sort by CPU usage, RAM usage, or process name
- Process detail panel showing category, risk level, description, and notes
- Self-contained single-file EXE — no .NET runtime installation required
- C# source code with .NET 8 Windows Forms, single-file publish
- README with features, use cases, and build instructions
- `.gitignore` excluding binaries and build artifacts
